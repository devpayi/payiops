# LINE จดคำขอร้าน — 14 กันยายน 2026

- ทุกคนในกลุ่มที่ผูกไว้แท็กบอทพร้อมคำขอได้ บอทตอบ “จดแล้ว” โดยไม่ quote
- แก้ไข/ยกเลิกด้วยการ quote ข้อความเดิมแล้วแท็กบอท เฉพาะผู้ขอหรือบอส
- บอสได้รับสรุป 17:00 และเตือนงานที่ยัง OPEN จากก่อน 17:00 วันก่อนอีกครั้งที่ 10:00 (Asia/Bangkok)
- หากเครื่องเริ่มช้า จะส่งรอบเช้าช่วง 10:00–16:59 หรือรอบเย็นช่วง 17:00–23:59 ครั้งเดียวต่อรอบ ไม่ส่งถ้าไม่มีงาน
- คำสั่งส่วนตัว “ต้องสั่ง” ใช้ reply API เฉพาะบอสที่ตั้งค่าไว้
- การ์ดแนวตั้ง สูงสุด 5 งานต่อการ์ด / 5 การ์ดต่อชุด มีหน้าถัดไปเมื่อเรียกดูมากกว่า 25 งาน
- สั่งแล้ว และ รอไปเอา ถือว่ารับจัดการแล้ว ออกจากรายการค้าง ไม่ต้องกดยืนยันรับของ
- เลื่อนเตือน: พักจนถึง 17:00 วันถัดไป การแก้ไขคำขอจะยกเลิกการพัก
- ยกเลิก: ออกจากงานค้าง
- ทำแล้วทั้งหมด: ปิดเฉพาะงานที่แสดงในการ์ดนั้น และ version ยังตรง ข้ามงานที่ถูกแก้ไข ไม่มีผลกับคำขอใหม่หลังสร้างการ์ด
- ไม่มีการแจ้งกลับกลุ่มเมื่อบอสกด ไม่มีการติดตามรับของ และไม่มีการบันทึกบัญชีจากปุ่มเหล่านี้
- ปุ่มใช้ postback เพื่อไม่แสดง token ในแชท มีอายุ 7 วัน กดซ้ำไม่ทำรายการซ้ำ
- เก็บผลตอบใน receipt เพื่อรองรับ webhook redelivery; reply หลัง commit เท่านั้น
- ใช้ migration 0005_line_workflow.sql ต่อจาก 0004 ห้ามแก้ migration ที่ติดตั้งแล้ว
- เปิดด้วย npm run ops:start ที่ root ของ mona-ops เครื่องต้องเปิดและต่ออินเทอร์เน็ต ระหว่างทดสอบใช้ HTTPS ชั่วคราว

อ้างอิงรูปแบบ Flex และ postback: https://developers.line.biz/en/reference/messaging-api/
